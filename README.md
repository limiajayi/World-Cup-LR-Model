# World Cup Logistic Regression Model

A simple project meant to take in two teams (Country A vs Country B) and predict the probability of each country winning that match.

## Currently Developing

Working on cleaning and using a [results.csv](https://www.kaggle.com/datasets/martj42/international-football-results-from-1872-to-2017/data?select=results.csv) file to get "the last 5 matches" feature of a country

Extracting all 48 countries in the 2026 World Cup by selecting unique countries participating in the group stage.
